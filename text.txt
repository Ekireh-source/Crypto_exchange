Adapter Abstraction (

BlockchainAdapter
):

All EVM networks (BSC, Ethereum, Polygon, local test nodes) implement standard methods: 

SendNative
, 

SendToken
, 

GetNativeBalance
, and 

EstimateFee
.
On-Chain Signing (

bsc/transfer.go
):

The backend retrieves the sender's encrypted private key from the database and decrypts it via AES-256-GCM.
It fetches the latest PendingNonceAt and SuggestGasPrice from the node RPC.
Signs the raw transaction using types.SignTx and broadcasts it to the RPC endpoint via SendTransaction.
2. How to Test on a Local Blockchain
You can run a local EVM node using Anvil (from Foundry) or Hardhat Node. This provides instant block mining and zero-latency transactions without using testnet faucets.

Step 1: Start a Local EVM Node
In a separate terminal, start Anvil or Hardhat:

bash
# Option A: Using Anvil (Foundry)
anvil
# Option B: Using Hardhat
npx hardhat node
This starts a local JSON-RPC server listening on http://127.0.0.1:8545 with chain ID 31337 (or 1337) and pre-funded test accounts.

Step 2: Configure Backend Environment
Update 

backend/.env
 to point to your local node:

env
ENV=development
BSC_TESTNET_RPC=http://127.0.0.1:8545
BSC_TESTNET_CHAIN_ID=31337
Step 3: Fund the User's Generated Deposit Address
Since newly generated deposit addresses start with a 0 balance on your local node, send a small gas amount (e.g., 1 ETH/BNB) from Anvil/Hardhat's pre-funded Account #0 to the user's deposit address:

bash
# Using cast (Foundry CLI tool)
cast send <USER_DEPOSIT_ADDRESS> --value 1ether --private-key 0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80 --rpc-url http://127.0.0.1:8545
Step 4: Test Send & Receive on the Dashboard
Receive Modal:
Click Receive crypto on the dashboard.
Copy the user's deposit address generated by the backend.
Send Modal:
Click Send crypto.
Paste a recipient address (e.g. Hardhat Account #1: 0x70997970C51812dc3A010C7d01b50e0d17dc79C8).
Enter amount and click Confirm & Send.
Verify:
The backend will sign and broadcast the transfer to http://127.0.0.1:8545.
Your local node terminal will print the mined transaction block and return the real on-chain transaction hash!
